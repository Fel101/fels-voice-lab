# AMD's ROCm 7.14 build of PyTorch 2.12 for Windows and Python 3.12, from AMD's own index
# (https://repo.amd.com/rocm/whl-multi-arch/), for the models the Lab runs only on a graphics card: the four Qwen3-TTS models,
# VoxCPM2 and Breeze TTS 2. On a computer with an AMD graphics card, tools/amd_build.py takes the model's own list
# (requirements/qwen-nvidia.txt, voxcpm-nvidia.txt or breeze-nvidia.txt), puts the torch and torchaudio below in place of its
# NVIDIA builds, and adds the ROCm runtime they load and the code for the card's chip: torch's kernels for the chip
# (amd-torch-device-<chip>, with amd-torch-device-gfx11 or amd-torch-device-gfx12-0 for the chips of RDNA 3 and 4) and the
# ROCm libraries' (rocm-sdk-device-<chip>). The chips are the Radeon chips of RDNA 1 to 4 that AMD publishes Windows code for:
# the Radeon RX 5000, 6000, 7000 and 9000 series, their Radeon PRO and AI PRO cards, and the Radeon graphics in Ryzen
# processors. Every line pins one file by its SHA-256, because AMD's index publishes none. rocm is a small Python package AMD
# publishes only as source: pip builds it after the wheels, with the setuptools the model's list pins (--no-build-isolation),
# so nothing it runs is unpinned. The Lab was checked with this build on an AMD Radeon AI PRO R9700 (gfx1201); the other chips
# have not been tried.
# To change a pin: take each file from AMD's index for one ROCm release, write its SHA-256 here, and run the speech check in
# each of the three installers on an AMD card.
