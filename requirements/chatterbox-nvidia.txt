# these two in place of the CPU builds: the CUDA 13.0 builds of PyTorch 2.12.0 (the same file as Kokoro's NVIDIA build) and of
# torchaudio 2.11.0, the newest torchaudio, from PyTorch's own index, pinned by their SHA-256 (1.9 GB). The Windows CUDA wheels
# carry their CUDA libraries inside them. chatterbox-tts 0.1.7 asks for PyTorch 2.6, whose newest CUDA build (12.6) has no
# code for GeForce RTX 50 series cards; Chatterbox Turbo loaded, spoke and cloned a voice with PyTorch 2.12 and torchaudio 2.11
# (their CPU builds) before this list was written. CUDA 13.0 needs a card from the GeForce GTX 16 or RTX 20 series or newer
# (RTX 50 included) and an NVIDIA driver of version 580 or later. The Lab has not been tried on an NVIDIA card yet.
